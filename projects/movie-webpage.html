Movie Webpage Project

Context

This project assignment involved working with a partner to create a website based on a fictional story about robots ending the world. The goal was to create a webpage that explained the story plot and presented information in an organized way.

Content

My partner and i started by planning how to divide the responsibilites so we could both contribute to this project. We discussed our ideas, decided what infomration to include, and worked together to put the website together. We used HTML to create different sections, add images, and organzie the text by adding class and id elements. We used CSS to customize the appearance by changing the background, adding borders,color text, and different font familys as well as adjusting the spacing.

Reflection

One thing we struggled with was margin and padding to the images. We experimented with different margin and padding settings but it didnt look right. It either made the images look too far from the border or it affected the overall layout. After trying different adjustments, We were able to make the webpage to our liking. We asked our classmates for help and it indeed helped us alot. This project taught me that small changes can make a big difference. Next time i would ask for help sooner rather than spending too much figuring it out by oursleves.
